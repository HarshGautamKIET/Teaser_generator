The single chart type in the product — no lines, no donuts, no axes boxes.

```jsx
<BarChart activeIndex={7} tooltip={{label:'Earnings', value:'$84,849.93'}}
  data={[{label:'Jan',value:18},{label:'Feb',value:26} /* … */]} />
```

Pair it with a legend dot ("● Earnings") and a period <Select> in the card header.
