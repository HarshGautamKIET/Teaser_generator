One pill button covering every fill Oripio uses; primary green is reserved for the main action in a surface.

```jsx
<Button variant="primary" size="lg" icon={<Icon name="upload" size={16} />}>Send Money</Button>
<Button variant="secondary" size="lg" icon={<Icon name="download" size={16} />}>Request Money</Button>
<Button variant="dark" size="md" icon={<Icon name="download" size={14} />}>Export</Button>
```

Variants: `primary` (green), `secondary` (--ink-100 grey), `dark` (near-black header action), `outline` (white + hairline, used for the date pill and Filter), `ghost`, `onBrand` (white on the green upgrade card). Sizes 32 / 38 / 44px. Hover darkens the fill one step; press scales to .985 — never a shadow lift.
