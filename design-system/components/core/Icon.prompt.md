Renders one Lucide glyph. Requires the Lucide UMD script on the page.

```jsx
<Icon name="layout-grid" size={17} />
<Icon name="wallet" size={15} strokeWidth={2.2} />
```

Names used across the kit: layout-grid, chart-pie, credit-card, file-text, layers, badge-dollar-sign, message-square-dot, settings, circle-help, log-out, search, mail, bell, upload, download, calendar, more-horizontal, lightbulb, list-filter, arrow-up-down.
